# User Management

User Management is available from **Settings → Manage Users** to authorized users with the `view-settings` permission.

## Find an account

1. Expand **Filters**.
2. Search by the user's name, email address, or employee ID.
3. Optionally filter by role, pharmacy location, or active status.
4. Use **Rows per page** to change the number of visible accounts.
5. Select a sortable column heading to switch between ascending and descending order.
6. Select **Reset filters** to return to the default list.

## Change access

1. Select **Edit access** beside the user.
2. Choose the assigned role, or choose **No assigned role** to remove role access.
3. Choose the user's pharmacy location.
4. Select **Save changes**.

Protected Super Admin accounts cannot be changed from this page.

## Activate or deactivate an account

1. Select **Deactivate** or **Reactivate** beside the account.
2. Review the confirmation message.
3. Confirm the action.

Administrators cannot deactivate their own account. Deactivation preserves the account and allows it to be reactivated later.
